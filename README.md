## Scripts

- `npm run dev` — executa o projeto em modo desenvolvimento.
- `npm run build` — gera build de produção.
- `npm run start` — inicia servidor com build pronto.
- `npm run lint` — roda validação eslint/prettier.

2. Rode `npm run dev` e acesse http://localhost:3000.
3. Ajuste conteúdos, cores e blocos conforme necessidade.
